# Website fonts

Inter and Source Serif 4 are self-hosted under the SIL Open Font License. The original license notices are preserved in this folder.

Downloaded from the Google Fonts CSS API on 2026-10-12. Latin and Latin Extended subsets, normal and italic styles, variable weights 400–700. Source Serif 4 includes optical sizing.

- Source Serif 4: https://github.com/adobe-fonts/source-serif
